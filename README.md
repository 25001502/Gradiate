# 🎓 Gradiate

**Gradiate** is an educational platform built to support learners, especially Grade 12 students, by giving them easier access to important academic and career-related information in one place. 🌍📚

It is designed to help students make better decisions about their future by providing useful tools, guidance, and resources for higher education opportunities.

## 🚀 Live Preview
🔗 **Visit Gradiate here:** [gradiate.co.za](https://gradiate.co.za)

## 📌 Project Overview
Gradiate was created with the vision of empowering students with the right information at the right time. Many learners struggle to find clear and reliable guidance about university applications, APS calculations, bursaries, and academic resources. Gradiate aims to solve that problem through a simple and user-friendly digital platform.

## ✨ Features
Some of the features available on Gradiate include:

- 🎯 **APS Calculator** to help learners calculate their Admission Point Score
- 🏫 **University Information** for exploring institutions and requirements
- 📄 **Past Papers / Academic Resources** for study support
- 💰 **Bursary Information** to help students discover funding opportunities
- 👤 **User Profiles** for a more personalized experience
- 🔖 **Bookmarking Features** for saving useful content
- 🌐 **Responsive Design** for smooth use on both mobile and desktop devices

## 🛠️ Technologies Used
Gradiate is built using modern web technologies, including:

- **React.js** ⚛️
- **Firebase** 🔥
- **Firestore Database** 🗄️
- **Firebase Authentication** 🔐
- **Firebase Hosting** 🌍
- **CSS** 🎨
- **JavaScript** 💻

## 🎯 Purpose of the Project
The purpose of Gradiate is to bridge the information gap faced by many students when preparing for university and career opportunities. It is more than just a website — it is a platform intended to guide, support, and motivate learners toward academic success. 📖✨
