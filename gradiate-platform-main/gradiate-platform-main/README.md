# Gradiate 🎓

**Gradiate** is a web-based platform designed to help students and graduates unlock educational opportunities. The platform intelligently matches:

-   📚 High school students with bursaries they qualify for
-   🎓 Graduates with suitable graduate programs

Our mission is to remove barriers to education by streamlining access to funding and advancement opportunities.

---

## 🚀 Features

-   🔍 Intelligent matching system for bursaries and graduate programs
-   📁 Profile-based filtering using academic background, interests, and qualifications
-   📊 Personalized dashboard for managing matched opportunities
-   🧑‍💼 Admin panel for managing and listing bursaries/programs
-   💬 (Planned) AI chatbot for application guidance and support
