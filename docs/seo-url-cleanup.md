# SEO URL Cleanup Plan

## What Was Added

SEO-friendly canonical routes were added in the router and legacy routes were kept for compatibility.

Canonical paths:

1. /auth
2. /application
3. /bursaries
4. /programs
5. /how-it-works
6. /about
7. /practice
8. /profile

Legacy paths still supported:

1. /AuthForm
2. /Aplication
3. /Bursaryguest
4. /Programsguest
5. /How
6. /About
7. /Practise
8. /Profile

## Why This Helps SEO

1. Lowercase, human-readable URLs improve crawl consistency.
2. Fixing typo-like paths (Aplication -> application) improves trust and clarity.
3. Canonical structure makes internal linking and sitemap quality stronger.

## Next Optional Step

Update navigation links across pages to use canonical paths so users and crawlers naturally land on the canonical URLs.
